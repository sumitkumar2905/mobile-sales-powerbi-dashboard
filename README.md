# 📱 Mobile Sales Analysis Dashboard | Power BI

## 📊 Project Overview

This project is an interactive **Mobile Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes mobile sales data to understand sales performance, customer behavior, mobile model performance, payment methods, cities, and monthly trends.

The main goal of this project is to transform raw sales data into meaningful and interactive business insights using **Power Query, Data Modelling, DAX, and Power BI Visualizations**.

---

## 🎯 Project Objectives

- Analyze overall mobile sales performance
- Identify top-performing mobile models
- Analyze sales trends over time
- Compare sales across different cities
- Understand customer purchasing behavior
- Analyze different payment methods
- Identify high-performing days and months
- Create an interactive dashboard for business analysis

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query**
- **DAX (Data Analysis Expressions)**
- **Data Modelling**
- **Data Visualization**

---

## 📌 Dashboard Features

### 💰 Sales KPIs

The dashboard provides important Key Performance Indicators such as:

- Total Sales
- Total Quantity Sold
- Total Transactions
- Average Sales

### 📈 Sales Trend Analysis

- Monthly sales analysis
- Monthly quantity analysis
- Identification of sales trends and patterns

### 📱 Mobile Model Analysis

- Sales performance by mobile model
- Comparison between different mobile models
- Identification of top-selling models

### 🌎 City Analysis

- Sales distribution across different cities
- Comparison of sales performance by location

### 💳 Payment Method Analysis

Analysis of transactions based on payment methods such as:

- UPI
- Credit Card
- Debit Card
- Cash

### 👥 Customer Analysis

The dashboard provides insights into customer purchasing patterns and transaction behavior.

### 📅 Day Analysis

Sales and transactions are analyzed based on different days of the week to identify high-performing days.

### 🎛️ Interactive Filters

Users can interact with the dashboard using filters/slicers such as:

- Month
- Brand
- City
- Payment Method

7. Preparing the data for modelling
